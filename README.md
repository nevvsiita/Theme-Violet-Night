# 💜 Cozy Violet Night 🐾 (Kitty Edition)

Un tema oscuro estético con tonos violeta, lavanda, rosa pastel y **Bongo Cat 🐱** integrado para **Antigravity IDE** y **VS Code**.

![Icono del Tema](icon.png)

---

## 🐱 Novedades Integradas

### 1. 🐾 Bongo Cat en la Barra de Estado (Status Bar Companion)
Basado en el repositorio [kitgore/BongoCat](https://github.com/kitgore/BongoCat):
- **Animación al escribir**: Las patitas del gato se mueven en la barra de estado mientras escribes código.
- **Comandos**:
  - `Toggle Bongo Cat`: Muestra u oculta la mascota en la barra de estado.

### 2. 🎀 Snippets de Código Gatito Kawaii (Autocompletado)
Puedes usar estos accesos directos en archivos `.js`, `.ts`, `.md`, `.html`, `.css`:
- `cathead` + `Tab`: Inserta un encabezado de comentario estilo gatito.
- `catascii` + `Tab`: Inserta un arte ASCII de gatito `( o.o )`.
- `catdiv` + `Tab`: Inserta una línea divisora decorativa con patitas `🐾 ──── (=^‧^=) ──── 🐾`.

### 3. 🎨 Paleta Pastel & Bracket Highlight Kawaii
- **Editor Background**: `#13111c`
- **Cursor & Accents**: `#f472b6` (Rosa Sakura pastel)
- **Corchetes Coloreados (Rainbow Brackets)**: Rosa (`#f472b6`), Lavanda (`#c084fc`), Menta (`#818cf8`), Magenta (`#fb7185`).

## 📁 Estructura del Proyecto

- `extension.js`: Lógica animada de Bongo Cat en la barra de estado.
- `bongocat-theme.json`: Definición del tema de iconos de Bongo Cat.
- `bongocat.woff`: Fuente tipográfica con los iconos de las patitas de Bongo Cat.
- `snippets/cat-snippets.json`: Snippets y comentarios decorativos de gatitos.
- `package.json`: Manifiesto oficial del paquete.
- `themes/cozy-violet-color-theme.json`: Definición completa de colores TextMate.
- `icon.png`: Icono oficial del tema.
- `.vscode/settings.json`: Configuración lista para usar.
