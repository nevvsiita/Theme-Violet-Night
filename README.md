# 💜 Cozy Violet Night 🐾 (Kitty Edition)

Un tema oscuro estético con tonos violeta, lavanda, rosa pastel y el popular **Bongo Cat 🐱** ([kitgore/BongoCat](https://github.com/kitgore/BongoCat)) integrado para **Antigravity IDE** y **VS Code**.

![Icono del Tema](icon.png)

---

## 🐱 Novedades Integradas

### 1. 🐾 Bongo Cat en la Barra de Estado
Mascota en la barra de estado idéntica a la extensión oficial `kitgore/BongoCat`:
- **Animación al escribir**: Las patitas se mueven en la barra de estado mientras escribes código.
- **Comando**:
  - `Toggle Bongo Cat`: Muestra u oculta la mascota en la barra de estado.

### 2. 🎀 Snippets de Código Kawaii (Autocompletado)
Accesos directos en archivos `.js`, `.ts`, `.md`, `.html`, `.css`:
- `cathead` + `Tab`: Inserta un encabezado decorativo.
- `catascii` + `Tab`: Inserta un arte ASCII.
- `catdiv` + `Tab`: Inserta una línea divisora decorativa.

### 3. 🎨 Paleta Pastel & Bracket Highlight
- **Editor Background**: `#13111c`
- **Cursor & Accents**: `#f472b6` (Rosa Sakura pastel)
- **Corchetes Coloreados (Rainbow Brackets)**: Rosa (`#f472b6`), Lavanda (`#c084fc`), Menta (`#818cf8`), Magenta (`#fb7185`).

---

## 📁 Estructura del Proyecto

- `extension.js`: Lógica nativa de Bongo Cat en la barra de estado.
- `bongocat-theme.json`: Definición del tema de iconos de Bongo Cat.
- `bongocat.woff`: Fuente tipográfica oficial de Bongo Cat.
- `snippets/cat-snippets.json`: Snippets decorativos.
- `package.json`: Manifiesto oficial del paquete.
- `themes/cozy-violet-color-theme.json`: Definición completa de colores TextMate.
- `icon.png`: Icono oficial del tema.
- `.vscode/settings.json`: Configuración lista para usar.
